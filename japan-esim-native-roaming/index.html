你買的日本 eSIM，是日本的網路還是繞回香港的？

「原生還是漫遊」不是一個問題，是兩個。第一個決定你的資料從哪個國家出去，第二個決定你尖峰時段會不會塞。多數人只問第一個。

技術說明對照 GSMA 漫遊規格與日本總務省原文，查證於 2026-09-23
會不會變成香港的網路，不是你決定的，也不是日本電信商決定的
GSMA 的規格寫明：漫遊時資料要走 Home Routed（先回發行方的國家再出去）還是 Local Breakout（就在日本出去），由發行方的母網逐條決定。所以只要你買到的是 Home Routed 漫遊，從連上的第一秒 IP 就在國外，不是用到一半才變。
而「用到一半變慢」通常是另一回事——吃到飽超量降速、MVNO 尖峰降速，或多 IMSI 產品切換到另一家日本電信商。最後那種是在日本國內換，不會讓 IP 跑到香港。

第一層：你的資料從哪個國家出去

漫遊 profile 的意思是，你那張 eSIM 由外國業者發行，在日本是訪客身分。GSMA 的漫遊規格把訪客的資料路由分成兩種——Home Routed（HR，資料先回到發行方所在地的網路才出去）與 Local Breakout（LBO，資料就在日本當地出去）。走 HR 的話，你的公網 IP 會落在發行方那個國家，香港、新加坡、英國都有可能。這就是「用到一半變成香港的網路」的真正來源。

選哪一種不是你決定的，也不是日本電信商決定的。GSMA NG.113 寫明：由 HPMN（發行方的母網）透過 subscription data 逐條決定這個連線要用 HR 還是 LBO。所以只要你買到的是 HR 漫遊，從連上的第一秒就是外國 IP，不是用到一半才變。

The HPMN can control via subscription data per DNN (Data Network Name) and per S-NSSAI (Single Network Slice Selection Assistance Information) whether a PDU Session is to be set-up in HR or in LBO mode.GSMA NG.113 5GS Roaming Guidelines v11.0，第 48 頁

出處：GSMA NG.113 5GS Roaming Guidelines v11.0、GSMA IR.88 EPS Roaming Guidelines v25.0（4G 時代同樣分 HR 與 local break-out），查證於 2026-09-23。

第二層：就算是原生，也分大手電信商與 MVNO

很多人以為「原生」就等於快，其實不是。日本的 MVNO 是向大手電信商租一段網路來賣，訊號涵蓋跟大手一樣，但尖峰時段會塞。這一點總務省自己的手機入口網站寫得很清楚。

電波のつながりやすさ（通信エリア）は、大手携帯会社と同じです。訊號涵蓋範圍跟大手電信商相同。
ネットワークの一部を借りているため、お昼休みや通勤時間帯、夜間等、通信が混み合う時間ではデータ通信速度が低下する場合もあります。因為只租用了網路的一部分，午休、通勤時段、夜間等壅塞時間，資料通訊速度有時會下降。

所以「原生」保證的是訊號涵蓋，不是速度。中午 12 點到 1 點在東京車站附近上網卡住，多半跟漫遊沒關係，是 MVNO 的頻寬問題。

出處：日本總務省 手機入口網站・格安スマホ／格安SIM とは，查證於 2026-09-23。

「用到一半變慢」多半不是變成別國網路

  1. 吃到飽超量降速——各家降到多少不同，商品頁通常寫在小字裡。
  2. 原生但走 MVNO，尖峰時段降速——總務省明載的那一條。
  3. 多 IMSI 產品在訊號差時切換到另一家日本電信商——那是在日本國內換電信商，不是換國家，IP 出口不會因此跑到香港。

真正會讓 IP 跑到國外的是 HR 漫遊，而那是從頭到尾如此，不是中途發生的。

買之前，商品頁的哪些寫法有線索

商品頁上的寫法代表什麼為什麼
同時列出多家日本電信商（例如「SoftBank 5G／docomo 4G LTE」）偏漫遊通常是多 IMSI 或轉售整合，不是單一日本電信商的原生門號
只寫「使用日本當地網路」「日本現地回線」無法判斷等於沒說。漫遊訪客用的也是日本當地網路，差別在資料從哪裡出去
把日本電信事業者寫成發行方，或直接掛日本 MVNO 品牌（例如商品名寫 NTT docomo／Sakura Mobile）偏原生比較可能是原生，但仍要看是大手還是 MVNO
供應商或賣家註冊在香港、新加坡偏漫遊若走 HR，出口 IP 很可能就在那裡

顏色只是標示「比較可能是哪一種」，不是好壞——原生跟漫遊各有適合的情境，下面那段有說明。另外商品頁多半不會直接寫，所以本站的 eSIM 比較表裡，profile 這一欄只在官方明載或供應商回覆時才填，其餘一律留白，不用評論推測來補。

啟用之後，三十秒自己驗

1. 看電信商名稱

iPhone：設定 → 行動服務 → 點那張 eSIM → 看「網路供應商」；螢幕最上方也會顯示。Android 在「設定 → 網路與網際網路 → 行動網路」。

顯示 NTT DOCOMO、SoftBank、KDDI 之類，代表你的無線電那一段接的是那家日本網路。但這只說明無線電，不代表 IP 出口在日本。

2. 查公網 IP 落在哪一國

開瀏覽器搜尋「my ip」之類的查詢服務，看它判斷你在哪個國家。

顯示日本＝本地出口；顯示香港、新加坡、英國＝你買到的是 Home Routed 漫遊。

3. 兩項合起來看

電信商是日本的、IP 也是日本的 → 原生或 LBO 漫遊，實務上沒差。電信商是日本的、IP 在國外 → HR 漫遊，該注意的是下面那些會被擋的服務。

IP 在國外，實際會影響什麼

  • 只對日本開放的網站與串流內容看不了——這是最常遇到的。
  • 部分日本網銀、政府與購票網站會擋海外 IP。
  • 延遲變高，因為資料要先繞回發行方的國家再出去。
  • 反過來說，如果你本來就想用台灣的服務，IP 不在日本反而方便。這一欄沒有絕對的好壞，看你要用什麼。

這頁還查不到的部分

寧可留白也不要寫成結論：

  • 漫遊訪客在網路壅塞時是否會被降低優先權
    業界確實有這種做法，但找不到可引用的公開消費者文件（電信商的壅塞管理政策多半不公開細節），所以不寫成結論。
  • 各商品實際上是原生、HR 漫遊還是 LBO 漫遊
    要逐一向供應商確認或實機測試。比較表的 profile 欄目前全部留白。

常見問題

我買的 eSIM 會不會用到一半變成香港或中國的網路？
如果你買到的是 Home Routed 漫遊，那不是「用到一半變成」，而是從連上的第一秒就是——你的資料會先回到發行方所在地的網路才出去，公網 IP 一直都在那個國家。反過來說，真正會「用到一半改變」的是速度：吃到飽超量降速、MVNO 尖峰降速，或多 IMSI 產品切換到另一家日本電信商。最後那一種是在日本國內換電信商，不會讓你的 IP 跑到國外。
原生 eSIM 是不是一定比較快？
不一定。日本的 MVNO 向大手電信商租一段網路來賣，總務省寫明訊號涵蓋跟大手相同，但「午休、通勤時段、夜間等壅塞時間，資料通訊速度有時會下降」。所以原生保證的是訊號涵蓋，不是尖峰速度。
商品頁寫「使用 docomo／SoftBank 網路」，這樣算原生嗎？
不算，那句話什麼都沒說——漫遊訪客用的也是日本當地電信商的網路，差別在資料從哪個國家出去。而且同時列出多家日本電信商，通常反而是多 IMSI 或轉售整合的特徵。
怎麼自己確認？
兩步：先看電信商名稱（iPhone 在設定 → 行動服務 → 點那張 eSIM），再用瀏覽器查自己的公網 IP 落在哪一國。電信商顯示日本、IP 也顯示日本，就是本地出口；電信商顯示日本但 IP 在香港或新加坡，就是 Home Routed 漫遊。只看電信商名稱不夠，那只說明無線電那一段。
IP 不在日本，實際會怎樣？
最常遇到的是只對日本開放的網站與串流內容看不了，部分日本網銀、政府與購票網站也會擋海外 IP，另外延遲會高一些。但這一欄沒有絕對的好壞——如果你本來就想在日本用台灣的服務，IP 不在日本反而方便。
為什麼這頁沒有列出哪個商品是原生、哪個是漫遊？
因為查不到。商品頁多半不寫，而這件事沒有可靠的第三方資料可抄。本站的作法是只在官方明載或供應商回覆時才填，其餘留白——所以先把判斷方法寫清楚，讓你自己驗。
